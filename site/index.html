What Unassigned is

Unassigned is a public, free link-sharing service operated in the United States. It lets you send a web link to someone by text message without revealing your identity. You are identified only by an anonymous handle such as ASSIGNED123ABC. This page is open to everyone. There is no password, no paywall and no sign-in.

How consent works

  1. A sender enters a recipient phone number and a link on this page.
  2. The recipient receives one single message asking permission. This first message contains no link, only the opt-in request.
  3. The recipient replies Y to consent. Only then is the link delivered.
  4. If the recipient does not reply, nothing further is sent. If they reply STOP they are opted out permanently and any held link is deleted.

Example of the one message a recipient receives before consenting:
Hi, this is Unassigned. You have a link from ASSIGNED123ABC. Reply Y to receive it. Reply STOP to opt out. Msg and data rates may apply.

Keywords: reply Y, YES or START to opt in. Reply STOP to opt out at any time. Reply HELP for help. Message frequency varies. Message and data rates may apply.
